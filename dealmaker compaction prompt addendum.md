### 3. WHICH ADVISOR TO USE WHEN

Add a section called:

## FRAMEWORK SELECTION GUIDE

Create a decision tree for which source/persona to invoke:

- Use **Ramit Sethi** for salary, job offers, freelance rates, comp scripts, fear reduction, and practice drills.
- Use **Chris Voss** when the other side is emotional, evasive, adversarial, pressuring, vague, or withholding information.
- Use **William Ury / Getting to Yes** when the relationship matters and both sides need a principled, durable agreement.
- Use **William Ury / Getting Past No** when the other side says no, stonewalls, attacks, delays, or refuses to collaborate.
- Use **Roger Dawson** for transactional bargaining, price negotiation, tactical leverage, and recognizing gambits.
- Use **Aryeh Bourkoff** for long-game dealmaking, strategic partnerships, reputation, trust-building, timing, and deciding whether a deal is worth doing at all.

Also include:
- Which frameworks are safest for high-trust relationships
- Which frameworks are best for adversarial or transactional contexts
- Which frameworks should be avoided if they would damage reputation or trust

### 4. ETHICAL MODE SELECTION

Add a section called:

## NEGOTIATION MODE SELECTION

Classify tactics into three modes:

### High-Trust / Principled Mode
Use when the relationship matters long-term.

Includes:
- Interests over positions
- Objective criteria
- Transparent constraints
- Mutual gain
- Golden bridge
- Empathy-first framing
- Long-game reputation protection

### Tactical / Commercial Mode
Use when the deal is professional, bounded, and both sides expect bargaining.

Includes:
- Anchoring
- Delaying live decisions
- Asking for flexibility
- Silence
- Multiple levers
- Higher-authority review if truthful or socially acceptable
- “What would need to be true?”

### Defensive / Adversarial Mode
Use when the other side pressures, manipulates, withholds, or corners the user.

Includes:
- Calibrated questions
- Labels
- Accusation audits
- Refusing to name numbers first
- Deflecting ultimatums
- Going to the balcony
- BATNA protection
- Walking away

Flag tactics that may be manipulative, trust-damaging, or inappropriate for close relationships.

### 5. PRACTICE PROTOCOLS

Add a section called:

## PRACTICE DRILLS

Do not only extract scripts. Extract how to practice them.

Include drills for:

### Salary Number Deflection
Practice until the user can calmly avoid giving a number first.

### Offer Response
Practice receiving an offer without accepting, rejecting, apologizing, or filling silence.

### Counteroffer
Practice making a clear ask using market data, scope, and fit.

### Silence Tolerance
Practice saying a sentence, then staying silent for 5–10 seconds.

### Pushback Handling
Practice responses to:
- “This is our best offer.”
- “What number are you looking for?”
- “We need an answer today.”
- “You’re already at the top of our range.”
- “We don’t negotiate equity.”
- “Why do you deserve that?”
- “Another candidate would accept this.”

### Hostile Recruiter / Founder Simulation
Create mock role-play prompts where the other party pressures, flatters, rushes, guilt-trips, or stonewalls.

For each drill, include:
- Goal
- Script
- Bad version
- Better version
- What to listen for
- When the user is ready

### 6. USER FAILURE-MODE INTERCEPTS

Add a section called:

## FAILURE-MODE INTERCEPTS

Extract or infer likely failure patterns from the user’s notes. For each one, include an interrupt script.

Examples:

### Over-Apologizing
Replace:
> “Sorry, I know this is annoying…”

With:
> “I understand this is a detailed conversation, and I want to make sure we find something that works for both sides.”

### Accepting Live
Replace:
> “Yeah, that sounds good.”

With:
> “Thank you. I’m excited about this. I’d like to review the full package and get back to you.”

### Explaining Too Much
Replace long justification with:
> “The number I’m looking for reflects the scope of the role, my experience, and current market data.”

### Fear of Being Difficult
Reframe:
> Negotiating professionally is not being difficult. It is part of closing a serious agreement.

### Filling Silence
Rule:
> After asking for flexibility or naming a counter, stop talking.

### Collapsing Under Pushback
Use:
> “I hear you. What would need to be true for us to get closer to that range?”
